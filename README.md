# ☕ 30 Days of Java

A personal challenge to learn and practice Java by writing and committing code every single day for 30 days straight.

![Java](https://img.shields.io/badge/Language-Java-orange)
![Progress](https://img.shields.io/badge/Progress-Day%201%2F30-brightgreen)
![Status](https://img.shields.io/badge/Status-In%20Progress-yellow)

## 📌 About This Challenge

The goal of this repo is simple: **code in Java every day for 30 days**, commit the work, and track progress publicly. Each day covers a new concept, small project, or coding exercise — starting from the basics and building up to more advanced topics.

Consistency > perfection. The code here won't always be polished, but it will be honest, daily practice.

## 🎯 Goals

- Build a solid foundation in Java syntax and OOP concepts
- Practice problem-solving with small daily programs
- Get comfortable with Git & GitHub workflow (daily commits)
- Build a public record of learning progress

## 🗂️ Repo Structure

```
30-days-of-java/
├── Day01/
│   └── Main.java
├── Day02/
│   └── Main.java
├── Day03/
│   └── Main.java
...
├── Day30/

```

Each `DayXX` folder contains that day's code, along with a short notes file (`notes.md`) explaining what was learned or built.

## 🚀 How to Run

Each day's code can be compiled and run individually:

```bash
cd Day01
javac Main.java
java Main
```

## 🛠️ Tech Stack

- **Language:** Java (JDK 17+)
- **IDE:** IntelliJ IDEA / VS Code
- **Version Control:** Git & GitHub

## 📖 Daily Workflow

1. Pick the day's topic
2. Write and test the code
3. Add a short `notes.md` with key takeaways
4. Commit and push before the day ends

```bash
git add .
git commit -m "Day XX: <topic>"
git push
```
